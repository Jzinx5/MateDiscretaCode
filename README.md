# Proyecto Prediccion Climatica con Markov

## Descripcion
Proyecto realizado con Python para analizar estados climaticos usando cadenas de Markov.

- Exportacion Excel
- Diagramas Mermaid
- Estadisticas climaticas

- Matplotlib
- Pandas
